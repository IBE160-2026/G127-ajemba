- (decision) Quiz feedback: MC and fill-gaps checked immediately per question, with link to source slides/summary part. - (decision) Summary layout: one long page, 'Jump to' list at top, clear heading per Summary Part, key terms panel beside each part (below on phone). Review list entries, quiz source links and essay feedback deep-link (anchor) to the exact part.
- (decision) IA: top bar (logo, My lectures, Upload, text size, Log out; menu button with text label on phone). Lecture page is hub with tabs: Summary, Multiple choice, Fill in the gaps, Essay, Results. Requirements: quiz progress/answers kept when switching tabs mid-quiz; on phone tabs are a scrollable row with short labels (e.g. Summary, Choice, Gaps, Essay, Results).
- (decision) Processing: calm waiting screen with real plain-language steps (Reading your PDF / Finding the key points / Writing the summary), no fake percentage; auto-opens Summary when done. If student leaves, processing continues; lecture shows 'Processing...' in My lectures until ready. Failure: clear message + Retry (FR-5), no partial summary. Note for architecture: processing must be a background job, not tied to the page request.
- (decision) Essay: one question at a time, large text box, hint 'Write 2 to 5 sentences. Spelling and grammar are not marked.' Feedback below answer in 3 blocks: What you explained well / What is missing / Read this part again (link to summary part). Edit+resubmit allowed, max 3 attempts per question (cost + encourages rereading); earlier attempts and feedback stay visible. NOTE: PRD has no resubmit/3-attempt rule - needs PRD update (FR-17/FR-7 cost, Attempt definition, Essay Rating of which attempt counts for results/review list). Demo mode: prepared answers selectable.
- (decision) Results: last essay attempt counts for score and review list; results page lists every essay attempt (e.g. 'Attempt 1: 1 of 3 points, Attempt 2: 3 of 3 points') so progress is visible.
- (decision) Login: one centred card with tabs Log in / Register; short product line; visible labels; Show password checkbox; field-level plain-word errors; no Forgot password link; register tab note: 'We can't reset passwords yet.
