- (decision) AD background: DB-backed queue, exactly ONE worker, django-q2 with ORM broker on SQLite (workers=1). Every job idempotent (skip if result already stored; state transitions guarded). Binds: summary/quiz generation/essay feedback. Prevents: work tied to request, duplicate runs/double AI cost. ADOPTED.
- (decision) Library choice django-q2 over django-tasks DB backend: django-tasks docs warned of duplicate execution on SQLite (issue #33, unconfirmed fixed), package says breaking changes any time; Django 6 core tasks has no production worker. django-q2 mature, ORM broker, README lists Django 4.2-6.0 (sources conflict; verify at install, pin version; latest seen 1.8.0). Risk: SQLite 'database is locked' -> WAL mode + timeout.
- (decision) AD start: one cross-platform Python start script (run.py via 'python run.py') launches web server and qcluster worker, works on Windows, stops both on Ctrl+C. Demo Mode works without key. ADOPTED.
